# Fortune-telling-bunny
This project is a cute fortune telling bunny following the guide from hack club athena's snowglobe program.
I used HTML, CSS, and a little bit of JavaScript for this project.
This is my first time using JavaScript. I had a little difficulty figuring that out, but got it eventually by searching up tutorials on W3e schools and following the guide.
